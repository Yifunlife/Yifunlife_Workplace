# 亦玩集团售后中心源码

本目录来自已发布版本 V10（2026-10-19，已清空运行时演示订单）。完整接入说明见上级目录《接入总看板说明.md》。

包含电脑与手机工作台、员工账号与权限、客户三语工作台、客户档案、专属链接、客户工单及后续云端处理、采购生产费用和安装/仓储/财务界面、标准 Excel 模板、数据库结构与迁移、校验脚本及测试。

客户提交及客户来源后续工单由 D1/R2 持久保存。内部手工填写/Excel 导入及部分独立部门界面仍有会话内状态；不能当成所有业务已完整云端化。

技术栈：React / TypeScript / Vinext / Cloudflare Workers / D1 / R2。Node.js >=22.13.0。安装：`npm ci`；检查：`node check.mjs` 和 `npx tsc --noEmit`；构建：`npm run build`。启动和部署前必须配置目标系统的数据库、文件存储及身份认证。

本包没有账号数据库、密码、密钥或业务附件；测试文件里的虚构数据仅用于自动化校验，不会自动导入业务界面。Excel 的“填写示例（不导入）”是填表说明。

`.openai/hosting.json` 已去除原站点项目编号，避免误发覆盖原站点。保留 DB / BUCKET 绑定名称供对接参考。
