# 亦玩安卓设备管理 0.1.0

首版为内部联调 APK，支持 Android 8.0（API 26）及以上。不是可替代厂商 MDM 的完整设备管理器。

## 已接通

- 固定连接集团 HTTPS 网站；使用管理员签发的 7 天有效、一次性绑定码。
- 安装编号与随机 256 位设备凭证持久保存在应用私有空间；禁止应用数据备份。
- 绑定成功后上报品牌、型号、Android/API 版本、Agent 版本、绑定游戏的版本及设备管理能力。
- 前台每 60 秒心跳；后台使用 JobScheduler 周期任务（15 分钟，系统可能延迟）。开机后恢复任务；强制停止应用后需手动打开。
- 后台撤销绑定后拒绝该设备的后续上报。

## 安装与绑定

1. 网站软件中心 → 产品中心 → 登记真实游戏包名。
2. 设备中心 → 绑定码管理 → 选择集团已有客户并填写场地、设备名称。
3. 安装此管理 APK，输入绑定码。只应安装公司可信渠道提供的 APK。
4. 返回网站更新状态，核对设备与游戏版本。

debug APK 仅用于内部联调，正式发布应使用公司保管的签名密钥。不要把签名私钥或设备凭证提交到仓库。生产版本不能依赖临时 CI debug 签名跨版本覆盖升级。

## 构建

使用 JDK 17、Gradle 8.9、Android SDK 35：

```
gradle :app:assembleDebug :app:lintDebug
```

仓库 Actions 的 Build Android Agent 自动构建并保留 debug APK。

## 权限和限制

应用仅请求网络、开机恢复和桌面可启动应用的可见性声明。不获取系统 root，不申请无障碍服务，不执行远程重启或静默安装。是否是 Device Owner 仅按系统实际上报，不因页面配置而自动获得权限。

默认仅能查询带桌面启动入口的游戏。无桌面入口的游戏需取得真实包名后补充精确 queries 声明，当前会显示“未安装或不可见”。

本阶段不支持：APK 分发及安装回执、远程命令、日志上传、功能授权、内容分发、对局采集、Webhook。设备绑定码只用于接入，不是付费功能许可证。软件中心中这些入口明确显示待接入。

设备身份是当前应用安装身份，清除应用数据、恢复出厂或卸载后身份可能丢失，需要管理员撤销旧绑定并签发新码；不承诺硬件机器码稳定不变。绑定请求使用同一安装凭证重试可恢复丢失的成功响应。
