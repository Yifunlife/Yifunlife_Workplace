# 亦玩安卓设备管理 0.2.0（内部联调版）

Android 8.0 / API 26 及以上；JDK 17、Gradle 8.9、Android SDK 35。构建命令：`gradle :app:assembleDebug :app:lintDebug`。

## 已实现

设备绑定与撤销、前台心跳、系统与游戏版本上报、后台周期任务、协议 v2 配置同步、任务租约和结果确认、Agent 自身诊断、SQLite 离线事件队列与云端逐批确认。

后台支持产品、集团客户引用、独立场地、功能定义、设备权益、内容包和内容权益、APK 文件元数据、更新/恢复/远程任务草稿、人工下发、执行器能力校验、告警规则、自动恢复、HMAC 签名 Webhook 和最多 6 次发送尝试。所有业务写入沿用软件中心权限并记录操作审计。

## 可直接测试

1. 网站登记实际游戏包名，新增集团客户下的场地，再签发一次性绑定码。
2. 安装管理 APK 并绑定，在后台核对设备信息。
3. 创建功能权益，配置同步后通过同签名桥接读取配置。
4. 创建“同步配置”或“采集管理端诊断”任务，保存草稿后人工下发，查看设备回执和诊断记录。
5. 可配置真实 HTTPS 回调；草稿不发送，启用后才对匹配的实际事件发送。

协议、租约重试、游戏桥接和厂商执行适配约定见仓库根目录 `android-integration.md`。

## 待真实设备接入

安装 APK、恢复旧版本、重启应用、重启设备和内容文件下载都不在本版本的能力声明中；后台保留任务资料并显示“待接入执行器”。不会伪造成功，也不会自动取得 Device Owner、root 或厂商权限。

APK、内容资料采用 HTTPS 文件地址及 SHA-256 等元数据，当前不提供大型二进制文件上传存储。文件字节、签名和包名的实际校验与安装回执属于后续执行器适配。恢复版本为人工选择旧包的任务框架，不保证 Android 允许降级，也不提供系统级回滚。

功能权益与内容配置已能下发和在到期前离线读取，但游戏应用需要接入配置并实现实际功能控制。当前离线配置最长 24 小时，并受最早权益到期时间限制。

同签名游戏桥接只允许相同签名证书应用使用；游戏与管理 APK 签名不同时需另做受验证的厂商桥接，不能直接把接收器改成无权限公开。

## 数据与运行边界

- 设备凭证仅保存在应用私有空间，禁止备份；设备身份是安装身份。卸载、清除数据或恢复出厂后需撤销旧绑定并重新绑定。
- 前台约每 60 秒同步；后台约 15 分钟周期任务受系统调度影响，强制停止应用后需手动打开。
- 本地事件上限 1000 条，每批 20 条，只有云端确认才删除；单条最多 8 KB。满队列返回失败，由事件源保留并重试，不静默丢弃。
- 云端事件保留 30 天，诊断只接收允许字段。禁止上传设备凭证、账号密码或未经授权的用户个人信息。
- 任务租约 10 分钟，最多 3 次尝试；未知执行结果需保留并人工核对。厂商执行器必须按任务 ID 幂等，不能每次重试重复执行有副作用的动作。
- Webhook 最多 6 次发送尝试；使用同一个 delivery ID，由接收方去重。支持公网 HTTPS、证书校验与 DNS 地址固定，不跟随跳转。
- 云端定时入口与公网隔离，由 Workers Cron 唤醒容器执行维护，后台页面显示最近检查时间。
- 安装包是内部 debug 签名，不适合正式分发。正式版需公司管理签名；旧测试版签名不同时需卸载后重绑，不能强制覆盖。
